# Virus TI Skin for OsTIrus (Mike Leone)

![License](https://img.shields.io/badge/license-GPL--3.0-blue.svg)
![Platform](https://img.shields.io/badge/platform-OsTIrus-lightgrey.svg)

## 📖 Description

This is a skin that recreates the look of the **Virus Control** plugin for the legendary
virtual analog synthesizer **Access Virus TI**, running in **OsTIrus** — a free
plugin by **The Usual Suspects** that emulates the **Access Virus TI / TI2 / Snow**.

The skin was created by **Mike Leone** and is distributed freely under the GPL-3.0 license.

## 📦 Contents

All skin files are located in the folder:

```text
Virus TI Skin for OsTIrus (Mike Leone)/
```

## 🚀 Installation

### Step 1. Download the skin

- Click the green **«Code»** button → **«Download ZIP»**, or
- Clone via Git:

```bash
git clone https://github.com/Mike-Leone/Virus-TI-Skin-for-OsTIrus.git
```

### Step 2. Locate the OsTIrus skins folder

OsTIrus skins are stored in the `skins` folder inside the `The Usual Suspects`
directory in your Documents folder.

**Windows:**

```text
C:\Users\YourName\Documents\The Usual Suspects\OsTIrus\skins
```

**macOS:**

```text
~/Documents/The Usual Suspects/OsTIrus/skins
```

> ⚠️ If the `skins` folder does not exist — create it manually.

### Step 3. Copy the skin folder

Unpack the downloaded archive and place the **entire skin folder**
into the `skins` folder.

Correct structure:

```text
Documents\The Usual Suspects\OsTIrus\skins\
└── Virus TI Skin for OsTIrus (Mike Leone)\
    ├── skin_files.rcss
    └── skin_files.rml
```

> ❌ **Do not drop the files loosely** and do not nest the folder inside
> another folder — OsTIrus will not detect the skin.

### Step 4. Select the skin in OsTIrus

1. Open **OsTIrus** in your DAW (Ableton, FL Studio, etc.).
2. **Right-click** on the plugin interface and select **«Settings»**,
   or press **ESC**.
3. In the menu that opens, select **«Skin»**.
4. The skin name will appear in the list — select it.

The skin applies immediately. Sound and presets are not affected.

### 🔍 If the skin does not appear in the menu

- **Check the folder nesting.** Inside `skins` there must be a folder
  named after the skin, and inside it — the skin files. Extra nesting
  (`skins/Skin/Skin/files`) breaks detection.
